# `insights/` — durable realizations

One idea per file, lowercase-kebab filenames, linked liberally with wiki-links in double
brackets. A link to a note that doesn't exist yet marks future work, not an error.

Frontmatter carries `tags` from `brain/tags.md`, and — in an engagement running more than one
project — `project:` naming the strand the realization belongs to, or `all` when it holds
across the engagement.

Insights are not decisions (those are dated, in `decisions/`) and not tasks — they are the
things you'd want a future session to already know.
