# `insights/` — durable realizations

One idea per file, lowercase-kebab filenames, frontmatter tags from `brain/tags.md`, linked
liberally with wiki-links in double brackets. A link to a note that doesn't exist yet marks
future work, not an error.

Insights are not decisions (those are numbered, in `decisions/`) and not tasks — they are the
things you'd want a future session to already know.
