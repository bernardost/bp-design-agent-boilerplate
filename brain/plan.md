# The plan

*The stage arc and each stage's exit bar. **Position** — which stage we are in today — stays
`now.md`'s to say. **Tasks** stay `tasks.md`'s. This file says where we are going and what ends
each leg, and it should never grow past one screen.*

**The rule that makes this file work: an exit bar is written when a stage is *entered*, as a
numbered decision.** A stage without a bar does not produce rigour — it produces a loop where
every next step is genuinely useful and nothing ever ends.
