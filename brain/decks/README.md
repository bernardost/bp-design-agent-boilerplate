# `decks/` — decks and client documents

One folder per deliverable, or one file where a single HTML page carries the whole deck.
`/deck` writes them and `brain/lenses/deck.md` is the standard they are judged against.

**These are deliverables, not projections.** A rendered page under `brain/` is usually
generated from a record and gitignored; a deck is the work itself, so it is committed.

Name a deck `YYYY-MM-DD-<topic>.html`. Say in the file, or in the commit, which mode it was
built for — **presented** (minimum text, somebody is talking over it) or **standalone** (it
has to carry itself) — because every judgment about how much text belongs on a page depends
on that answer.
