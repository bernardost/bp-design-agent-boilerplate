# `references/` — the quality bar, as images

Drop images here that show the standard the work is measured against. `brain/lenses/craft.md`
points at this directory, and both `/reviewer craft` and `/critique` read it.

**Measure against, never copy toward.** A reference sets the height of the bar; it is not a
target to converge on. A critic told to copy produces pastiche, and pastiche scores worse
than an honest miss.

## What earns a place here

- Work whose *execution* is the standard, whatever its subject.
- The client's own material when it is genuinely good — and note when it is here as a
  constraint rather than as an aspiration, because those pull opposite ways.
- Anti-references, in `against/`. Knowing what the owner will not ship is cheaper feedback
  than three rounds discovering it.

## Naming

`<what-it-demonstrates>-<source>.png` — `density-bloomberg.png`, `type-scale-pentagram.png`.
The filename is what a critic reads first, so name the lesson, not the brand.

## Confidentiality

Client or third-party material here falls under `confidential.paths` in
`brain/workspace.toml` and stays out of git like anything else from outside. Add the path
there before adding the file, not after.
