# `briefings/` — what the outside world did

`YYYY-MM-DD.md`, one per `/briefing` run, pulled from the sources declared in
`brain/sources.md`. Same contract as a braindump: the file is the dated record, processing
routes decisions, insights, tasks and questions out to their owning files, and the briefing
never owns anything itself.

**Every line carries its source, its author, and its date**, with a link where one exists.
A line that cannot be attributed does not get written — see the label-evidence rule in the
charter.

These files hold other people's words. If the project's material is confidential and the
remote is not private, this directory belongs in `.gitignore`.
